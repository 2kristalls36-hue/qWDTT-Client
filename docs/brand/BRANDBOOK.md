# Брендбук qWDTT Client

Документ устанавливает правила использования логотипа, фирменных цветов и шрифтов приложения qWDTT Client. Правила обязательны для интерфейса приложения, иконок, страницы репозитория и материалов о проекте.

Файлы логотипа находятся в этой папке. В коде приложения логотип и фирменные цвета заданы в `app/src/main/java/com/wdtt/client/ui/theme/Brand.kt`.

## 1. Название

Название пишется так: **qWDTT Client**. Буква «q» строчная, «WDTT» прописные, «Client» с прописной буквы, между словами пробел.

Недопустимые написания: QWDTT Client, Qwdtt Client, qwdtt client, qWDTT-Client, qWDTTClient. Исключение составляют технические идентификаторы (имя репозитория, имя пакета), где действуют собственные правила.

## 2. Состав логотипа

Логотип состоит из двух строк: сверху «Client», под ним «qWDTT». Обе строки наклонены на 6° вверх, как на иконке приложения.

| Часть | Шрифт | Особенности |
|---|---|---|
| «Client» | Great Vibes | Верхняя строка, главный элемент. Тонкое начертание: контуры букв объединены, по краю снята полоса 0,575 единицы. |
| «qWDTT» | Poppins, жирный курсив | Нижняя строка. Набрано контурами, а не шрифтом. |

Оба шрифта распространяются по лицензии SIL Open Font License. В приложение шрифты не встраиваются, используются только контуры букв.

Слова логотипа не располагаются в одну строку.

## 3. Версии логотипа

| Версия | Файл | Где применяется |
|---|---|---|
| Знак приложения | `qwdtt-client-icon.svg` | Иконка на рабочем столе, страница релиза, магазин приложений. Белый логотип на неоновом фоне; логотип занимает всю видимую область иконки. |
| Логотип | `qwdtt-client-logo-dark.svg`, `qwdtt-client-logo-light.svg` | Заголовок главного экрана, шапка README, документы. Две строки без фона: белый на тёмном, «Ночь» на светлом. |
| Малый знак | `qwdtt-client-mark.svg` | Плитка в шторке, места размером меньше 32 dp. Только «Client» с волной. |
| Монохромный знак | `qwdtt-client-mono.svg` | Тематические иконки Android 13+, печать в один цвет. |

## 4. Охранное поле и минимальный размер

Охранное поле равно высоте прописных букв «qWDTT» (обозначается *H*) со всех сторон логотипа. В охранное поле не помещаются текст, значки и края других элементов.

Минимальные размеры:

- логотип — 64 dp по ширине (высота прописных «qWDTT» не меньше 8 dp);
- знак приложения — 24 dp;
- малый знак — 16 dp.

## 5. Цвета

### Фирменные цвета

| Название | Значение | Назначение |
|---|---|---|
| Ночь | `#0D0D0F` | Логотип на светлом фоне. |
| Белый | `#FFFFFF` | Логотип на тёмном фоне, логотип на знаке приложения. |
| Неон знака | `#B026FF` → `#3D5AFE` → `#FF2BD6` | Фон знака приложения: линейный градиент по диагонали из левого верхнего угла в правый нижний. |

Цвета неона знака взяты из неона уровня «Максимальный» светлой темы (без бирюзового).

### Цвета уровней мощности

Цвет уровня мощности окрашивает логотип в заголовке главного экрана, выбранную вкладку и элементы управления.

| Уровень | Светлая тема | Тёмная тема |
|---|---|---|
| Стабильный | `#1565C0` | `#A8D0FF` |
| Сбалансированный | `#1B9E45` | `#4ADE80` |
| Максимальный (неон) | `#B026FF` → `#00E5FF` → `#FF2BD6` → `#3D5AFE` | `#C04BFF` → `#00F0FF` → `#FF3DE0` → `#5C7CFF` |

Неон уровня «Максимальный» применяется только как перетекающая заливка в пределах формы (буквы, дорожка ползунка, ободок кнопки). Отдельные неоновые пятна и свечения вне формы не используются. Исключение — фон знака приложения: на нём неон знака лежит неподвижным градиентом.

### Нейтральные цвета интерфейса

| Назначение | Светлая тема | Тёмная тема |
|---|---|---|
| Фон | `#F3F8FF` | `#0F1722` |
| Карточки | `#DFE7F2` | `#233141` |

## 6. Шрифты

| Назначение | Шрифт |
|---|---|
| Логотип: «qWDTT» | Poppins, жирный курсив (контуры) |
| Логотип: «Client» | Great Vibes, тонкое начертание (контуры) |
| Интерфейс | Inter: Regular, Medium, SemiBold, Bold |

Шрифты логотипа не используются для обычного текста интерфейса.

## 7. Логотип в интерфейсе

В заголовке главного экрана логотип окрашивается в цвет текущего уровня мощности и плавно меняет цвет при перемещении ползунка. На уровне «Максимальный» сквозь буквы проходит неоновая заливка плашки мощности.

Во всех остальных местах логотип используется в одном цвете: белый на тёмном фоне, «Ночь» на светлом.

## 8. Недопустимое использование

- Растягивать и сжимать логотип непропорционально.
- Менять наклон, взаимное расположение и размеры частей, ставить слова в одну строку.
- Использовать «Client» в жирном начертании или с обводкой.
- Добавлять тени, обводки, градиенты и свечения, кроме неона уровня «Максимальный» в интерфейсе и неонового фона знака приложения.
- Окрашивать логотип в цвета, которых нет в разделе 5.
- Размещать логотип на пёстром фоне без подложки.
- Набирать логотип шрифтом вместо контуров.

## 9. Тексты интерфейса

Тексты приложения подчиняются правилам из раздела «Тексты интерфейса» файла `CLAUDE.md` в корне репозитория: формальный нейтральный тон, только факты, без давления и технических подробностей, действующее лицо — приложение.
