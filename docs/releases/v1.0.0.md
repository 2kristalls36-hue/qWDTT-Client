Первый выпуск qWDTT Client — клиента для подключения к серверу qWDTT.

## Назначение

- **Только подключение.** Серверная часть исключена: установка сервера на VPS и администрирование отсутствуют. Профиль подключения выдаёт владелец сервера.
- **Наглядный интерфейс.** Одна кнопка подключения, понятные уровни мощности, этапы подключения на экране, сведения о соединении без технических терминов.
- **Контроль подписки.** Срок действия, число привязанных устройств и заблаговременное предупреждение об окончании подписки.
- **Для пользователей подписки.** Приложение рассчитано на пользователей, которые приобрели подписку у владельца сервера и не администрируют его.

## Возможности

- Подключение в режиме RAW через звонки VK одной кнопкой; время, трафик и пинг до сервера на главном экране.
- Три уровня мощности: «Стабильный», «Сбалансированный», «Максимальный».
- Индикация этапов подключения на кольце кнопки; при сбое указывается этап, на котором он произошёл.
- Карточка подписки: остаток дней, дата окончания, число устройств, предупреждение за 1, 3 или 7 дней.
- Добавление профиля по QR-коду, ссылке или файлу с предварительной проверкой сервера.
- Перенос профиля на другое устройство с отвязкой текущего устройства.
- Авторизация через VK: ссылка на звонок создаётся автоматически, если она не указана в профиле.
- Обход: отдельные списки приложений для режимов «Мимо туннеля» и «Только выбранные»; сайты, IP-адреса и подсети вне туннеля.
- Подключение при включении устройства, виджет, кнопка в шторке быстрых настроек.
- Проверка и установка обновлений из GitHub Releases с проверкой контрольной суммы.
- Светлая и тёмная тема, вибрация с возможностью отключения.
- Бета-функции: жидкое стекло (Android 13 и новее) с настройкой прозрачности, «магнит» для ползунков, вкладок и списков.

## Сравнение с qWDTT

| | qWDTT | qWDTT Client |
|---|---|---|
| Назначение | Владелец сервера: установка, администрирование и подключение | Пользователь подписки: только подключение |
| Установка сервера на VPS | Есть | Нет |
| Администрирование сервера и профилей | Есть | Нет |
| Режимы подключения | VPN (WireGuard), SOCKS, RAW | RAW |
| Выбор нагрузки | Число потоков | Три уровня мощности без технических параметров |
| Срок подписки | В списке профилей и в администрировании | Отдельная карточка: остаток дней, дата, устройства, предупреждение заранее |
| Этапы подключения | Схема с техническими этапами | Кольцо на кнопке и подпись этапа простыми словами |
| Добавление профиля | Импорт ссылки или файла | Импорт с предварительной проверкой сервера, мест для устройств и срока подписки |
| Перенос на другое устройство | Экспорт профиля и отвязка устройства отдельными действиями | Единый перенос: QR-код или ссылка вместе со ссылкой на звонок, затем отвязка этого устройства |
| Списки приложений | Общий список для обоих режимов | Отдельный список для каждого режима |
| Ссылка на звонок VK | Вручную или создание в настройках | Вручную или автоматически перед подключением через авторизацию VK |
| Оформление | Стандартное | Интерфейс в стиле ARDTT, жидкое стекло и анимации |

## Установка

Для большинства телефонов подходит файл `arm64-v8a`; если архитектура устройства неизвестна, следует использовать `universal`. Последующие версии устанавливаются из приложения: «Настройки» → «Обновления».

qWDTT Client основан на исходном коде [qWDTT](https://github.com/SpaceNeuroX/proxy-turn-vk-android) и распространяется по лицензии GNU GPL v3.
