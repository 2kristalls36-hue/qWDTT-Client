Обновление qWDTT Client 1.2.1.

Исправления:
- При включённом параметре «Постоянная VPN» в настройках Android приложение подключается к выбранному профилю после перезагрузки устройства и обновления приложения.
- Описание обновления в разделе «Настройки» → «Обновления» отображается без служебных символов.

Установка:
- Для большинства телефонов подходит файл arm64-v8a; если архитектура устройства неизвестна, следует использовать universal.
- Версии 1.1.0 и 1.2.0 предложат обновление в разделе «Настройки» → «Обновления».

qWDTT Client основан на исходном коде [qWDTT](https://github.com/SpaceNeuroX/proxy-turn-vk-android) и распространяется по лицензии GNU GPL v3.
